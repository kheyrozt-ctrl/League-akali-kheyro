## Distribution checklist

When publishing a source release or compiled executable:

1. Keep the upstream copyright and license notices.
2. State that the work has been modified and include the modification date in the release notes.
3. Publish this repository, including the build configuration and lockfile, as the corresponding source for the executable.
4. Link the exact source commit from the release containing the executable.
5. Keep the third-party notices and the Riot Games disclaimer with the release.
